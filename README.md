# Tela Desktop

Instaladores e atualizações do Tela Desktop para Windows x64.

Player: https://tela-player-r8x4q.vercel.app

Baixe o instalador da publicação mais recente. A partir da versão 1.3, o programa verifica atualizações ao abrir, mostra o progresso de download e reinicia após a instalação.

NVIDIA NVENC, áudio com filtro para Discord, FPS ajustável, player com volume, qualidade e miniatura (Picture-in-Picture). No iPhone, abra o link no Safari e toque no botão de miniatura durante a reprodução.
